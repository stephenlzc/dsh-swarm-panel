## 必须遵守的 DSH 约定（全里程碑适用，违反会被拒）

1. **model-visible ⟺ logged**：进入模型请求的内容必须能从 session log 重建；新事件必须是 `SessionEventMap` 成员，且同步加入 `index.ts` 的 `SWARM_EVENT_TYPES` 运行时注册列表。
2. **registrations are effects**：所有注册走 `ctx.effect()` / `ctx.on()` 并返回 disposer；dispose 逆向清理；禁止模块级可变单例。
3. **Session event**：`session.events` 是 `readonly SessionEvent[]`，event 有 `.type`/`.data`；用 `session.append(type, data)`（不传泛型）；`session.id` 是 getter。
4. **defineTool**：`parameters` 是纯 JSON Schema；`output.schema` 是 `oneOf` 判别联合（成功值 + `{code,message}`）；`output.render` 是 `(args, value) => ContentBlock[]`；`execute` 返回类型必须显式标注精确 union。
5. **exactOptionalPropertyTypes**：可选字段条件展开 `...(x !== undefined ? { f: x } : {})`。
6. **branded IDs**：跨边界用 `SessionId(str)` 等工厂函数。
7. **No hardcoded tunables**：部署相关选择必须是 Config 字段（cordis.yml 可改），非法值加载即抛。
8. **测试**：mock `ctx.subagents.startContinuable`/`followup` 避免真实子 agent 跑模型；新事件词表注册后 persistence 读写路径才可重放。
9. 双语 README（README.md / README.zh.md）随行为变更同步更新。
